## Method and limits

Android and provider claims use official documentation. Training references distinguish workload measurement, observational findings, product descriptions and open-source implementations. Coaching thresholds are original engineering defaults requiring validation. Private reference screenshots and real activity data are not included. The Community design reference is linked for later visual inspection; no exact source font or token extraction is claimed.
